# 🎬 React Router Movie App

Live Demo: **https://react-router-movie-shrabani.netlify.app**

A responsive movie search & details app built with React Router and OMDB API.

### ✨ Features
- Movie details page with Poster, Plot, Cast, IMDb Rating
- React Router v6 - Nested Routes, Loader
- Fallback poster for N/A images
- Fully responsive & deployed on Netlify

### 🛠️ Tech Stack
- React + Vite
- React Router DOM
- OMDB API
- Tailwind CSS
- Netlify

### 🚀 Run Locally
```bash
npm install
npm run dev
